# Habit Tracker Bot

Telegram-бот для личного и публичного использования: пользователь создаёт привычки, выбирает дни недели, количество повторений, описание одного повторения и время напоминания. Выполнение отмечается нативными кнопками внутри Telegram Rich Messages.

## Возможности MVP+

- создание привычки через пошаговый FSM;
- дни недели: любые выбранные дни или каждый день;
- отдельное время напоминания для каждой привычки;
- ежедневный Rich Message-экран с прогрессом и кнопками повторений;
- SQLite + async SQLAlchemy;
- сохранение Telegram-профиля: `id`, `first_name`, `last_name`, `username`, часовой пояс;
- мягкое удаление привычек без потери прошлой статистики;
- текущая серия дней без пропусков;
- личный рекорд серии;
- визуальный календарь статистики за 5 календарных недель;
- общий процент выполнения и счётчики повторений;
- умные мотивационные уведомления;
- milestone-похвала на сериях 3/7/14/21/30/50/75/100/180/365 дней;
- интерфейс основных экранов на Telegram Rich Messages.

## Как считается серия

Серия считается по запланированным дням, а не по календарным дням подряд. Если привычки назначены только на понедельник, среду и пятницу, вторник и четверг не обрывают серию.

В запланированный день должны быть полностью выполнены все привычки этого дня. Пока текущий день ещё не закончился, незакрытый сегодняшний план не обнуляет уже активную серию — бот показывает её как серию, которую ещё можно сохранить.

Удаление привычки не стирает прошлые результаты. Незакрытое задание удаляемой привычки за текущий день снимается с сегодняшнего плана, чтобы невозможное к выполнению задание не ломало серию.

## Умные уведомления

Планировщик запускается с интервалом `SCHEDULER_INTERVAL_SECONDS` и учитывает часовой пояс пользователя.

1. В момент, когда наступает время напоминания хотя бы одной привычки, бот отправляет дневной Rich Message.
2. После 15:00, если план ещё не закрыт, отправляется одно контекстное напоминание. Текст зависит от прогресса: 0%, частично или почти готово.
3. После 20:00, если день всё ещё не закрыт, приходит отдельное предупреждение о риске потерять активную серию.
4. После полного выполнения дня бот отмечает milestone или новый личный рекорд.

Для защиты от спама используется таблица `notification_logs`: один тип умного уведомления отправляется не более одного раза в день.

## Запуск

Требуется Python 3.12+.

```bash
cp .env.example .env
```

В `.env` укажите токен:

```env
BOT_TOKEN=123456:ABCDEF
DATABASE_URL=sqlite+aiosqlite:///habit_bot.db
DEFAULT_TIMEZONE=Europe/Samara
SCHEDULER_INTERVAL_SECONDS=60
```

С `uv`:

```bash
uv sync
uv run main.py
```

Либо через стандартный `pip`:

```bash
pip install -e .
python main.py
```

## Команды

- `/start` — главный экран;
- `/new` — добавить привычку;
- `/today` — план на сегодня;
- `/habits` — список и удаление привычек;
- `/stats` — календарь, текущая серия, рекорд и общая статистика;
- `/timezone Europe/Samara` — изменить часовой пояс;
- `/help` — справка.

## Rich Messages

Проект рассчитан на aiogram 3.31.0 / Telegram Bot API 10.3. Таблицы используются для статистики и календаря, а интерактивные действия оформлены через `tg-button` / `tg-button-row`. Это сделано намеренно: Telegram допускает в ячейках Rich Message-таблиц только inline-форматирование, поэтому кнопки не помещаются внутрь `<td>`.

## База данных

`Base.metadata.create_all()` автоматически создаёт новые таблицы при первом запуске. В этой версии добавлена таблица `notification_logs`; существующая SQLite-база может продолжить использоваться без удаления.

Изменение существующих колонок в будущем лучше делать через Alembic. Для текущего обновления миграция колонок не требуется — добавляется только новая таблица.
