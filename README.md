# Surok Habits Bot

Простой Telegram-бот, который помогает не забывать о привычках и обычных делах.

Например, можно создать привычку «Зарядка», выбрать дни недели, указать несколько действий внутри неё и получать напоминания в нужное время. Бот покажет прогресс за день, серию выполненных дней и календарь за текущий месяц.

## Что умеет бот

- создавать привычки с любым количеством повторений;
- давать отдельное название каждому повторению: например, «выпить воду», «принять витамины», «прогуляться»;
- выбирать дни недели для привычки;
- задавать несколько напоминаний в день для привычки;
- создавать обычные напоминания через `/mem`;
- отмечать выполненные действия кнопками в сообщении Telegram;
- показывать план на сегодня, статистику, текущую серию и рекорд;
- показывать календарь выполнения за текущий месяц;
- учитывать часовой пояс каждого пользователя;
- присылать мягкие напоминания, если дневной план ещё не закрыт.

## Команды в Telegram

| Команда | Что делает |
| --- | --- |
| `/start` | Открывает приветственное сообщение. |
| `/new` | Создаёт новую привычку. |
| `/mem` | Создаёт обычное напоминание. |
| `/today` | Показывает план на сегодня. |
| `/habits` | Показывает список привычек и позволяет удалить привычку. |
| `/stats` | Показывает статистику и календарь текущего месяца. |
| `/timezone` | Показывает, как изменить часовой пояс. |

## Как запустить бота: пошагово

Ниже — самый простой вариант запуска на своём компьютере. Ничего отдельно устанавливать для базы данных не нужно: бот сам создаст файл базы данных при первом запуске.

### Шаг 1. Установите Python

Нужен **Python 3.12 или новее**.

1. Откройте [python.org/downloads](https://www.python.org/downloads/).
2. Скачайте Python для своей системы.
3. Во время установки на Windows обязательно поставьте галочку **Add Python to PATH**.
4. Закройте и снова откройте терминал после установки.

Проверьте установку:

```bash
python --version
```

В ответ должна появиться версия `3.12` или новее.

### Шаг 2. Скачайте проект

Если у вас установлен Git, выполните:

```bash
git clone <ссылка-на-репозиторий>
cd surok-habits-bot
```

Если Git пока нет — на странице репозитория нажмите **Code → Download ZIP**, распакуйте архив и откройте терминал в папке проекта.

### Шаг 3. Создайте своего Telegram-бота

1. Откройте Telegram.
2. Найдите бота [@BotFather](https://t.me/BotFather).
3. Отправьте ему команду `/newbot`.
4. Придумайте имя и username для своего бота.
5. BotFather пришлёт **токен** — длинную строку вида:

```text
123456789:AAExampleToken
```

Никому не отправляйте токен и не публикуйте его в интернете: с ним можно управлять ботом.

### Шаг 4. Установите uv

`uv` сам установит все нужные библиотеки для проекта.

- Windows (PowerShell):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

- macOS и Linux:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

После установки закройте и снова откройте терминал.

### Шаг 5. Создайте файл настроек

В папке проекта создайте файл `.env` из примера.

**Windows (cmd):**

```bat
copy .env.example .env
```

**Windows (PowerShell), macOS или Linux:**

```bash
cp .env.example .env
```

Откройте файл `.env` любым текстовым редактором и вставьте токен после `BOT_TOKEN=`:

```env
BOT_TOKEN=сюда_вставьте_токен_от_BotFather
DATABASE_URL=sqlite+aiosqlite:///./habit_bot.db
DEFAULT_TIMEZONE=Europe/Moscow
SCHEDULER_INTERVAL_SECONDS=20
```

Сохраните файл.

> Файл `.env` уже исключён из Git. Не выкладывайте его в репозиторий и не отправляйте другим людям.

### Шаг 6. Установите зависимости

В терминале, находясь в папке проекта, выполните:

```bash
uv sync
```

Первый запуск может занять несколько минут: программа скачает нужные библиотеки.

### Шаг 7. Запустите бота

```bash
uv run python main.py
```

Если в терминале нет ошибок — бот запущен. Откройте его в Telegram и отправьте `/start`.

Чтобы остановить бота, вернитесь в терминал и нажмите `Ctrl + C`.

## Первый запуск в Telegram

1. Отправьте боту `/start`.
2. Укажите свой часовой пояс. Например:

```text
/timezone +1
```

`+1` означает «на один час позже Москвы» — например, Самара. Москва — это `0`, Екатеринбург — `+2`.

3. Создайте привычку командой `/new` и отвечайте на вопросы бота.
4. Или создайте простое напоминание командой `/mem`.

Во время создания привычки или напоминания можно нажать кнопку **Отмена**. Ничего не сохранится.

## Как работают напоминания

Бот проверяет расписание примерно раз в 20 секунд. Когда наступает указанное время, он отправляет сообщение в Telegram.

Компьютер или сервер, на котором запущен бот, должен быть включён и иметь доступ к интернету. Если закрыть терминал или выключить компьютер, напоминания временно перестанут приходить.

## Где хранятся данные

По умолчанию все данные хранятся в файле `habit_bot.db` рядом с проектом. Это обычная SQLite-база данных.

Чтобы сделать резервную копию, остановите бота и скопируйте файл `habit_bot.db` в безопасное место.

## Если что-то не работает

- **`uv` не найден:** закройте и снова откройте терминал после установки uv.
- **Бот не отвечает:** проверьте токен в `.env`, затем перезапустите команду `uv run python main.py`.
- **Напоминания приходят не вовремя:** выполните `/timezone` и задайте правильное смещение от Москвы, например `/timezone +1`.
- **Ошибка после обновления проекта:** выполните `uv sync`, затем снова запустите бота.

## Для разработчиков

Основные файлы:

```text

handlers/user_router.py   # команды и диалоги с пользователем
services/scheduler.py     # отправка напоминаний
database/                 # модели и работа с SQLite
.env.example              # пример настроек
```

Проект использует Python 3.12+, aiogram, SQLAlchemy и SQLite.
